# 간호조무사 모의고사

간호조무사 국가시험 대비 연습 사이트입니다. 설치 없이 브라우저에서 바로 동작해요.

- **실전 모의고사**: 4과목 105문항 · 5지선다 · 105분 타이머 · 합격/불합격 판정 (과목별 40%, 전체 60%)
  - 국시원 2026년도 간호조무사 국가시험 기준 (출제범위: 2025년 상반기 적용분 + 2026년 상반기부터 의료관계법규에 「간호법」 추가)
- **과목별 연습**: 한 문제씩 바로 정답과 해설 확인
- **오답노트**: 틀린 문제만 모아 다시 풀기 (오답노트에서 맞히면 자동으로 빠짐)
- 문제·보기 순서 매번 섞기, 풀던 시험 이어서 풀기, 최근 기록, 다크 모드, 휴대폰 지원

> 문제는 직접 만든 연습용 문제이며 실제 기출문제가 아닙니다. 기록은 사용하는 브라우저에만 저장돼요.

---

## 1. 내 컴퓨터에서 열어보기

`index.html` 파일을 더블클릭하면 바로 열립니다.

## 2. GitHub Pages로 올리기 (무료, 휴대폰에서도 접속)

### 처음 한 번만

1. [github.com](https://github.com)에 가입하고 로그인합니다.
2. 오른쪽 위 **+** → **New repository** 를 누릅니다.
   - Repository name: 예) `nurse-quiz`
   - **Public** 선택 (무료 계정에서 Pages를 쓰려면 Public이어야 해요)
   - **Create repository** 클릭
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 이 폴더 안의 **`index.html`, `style.css`, `app.js`, `data` 폴더**를 통째로 끌어다 놓습니다.
   (`.claude` 폴더는 올리지 않아도 됩니다)
5. 아래 **Commit changes** 를 누릅니다.
6. 저장소 상단 **Settings** → 왼쪽 메뉴 **Pages** 로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** 선택 → **Save**
7. 1~2분 뒤 같은 화면 위쪽에 주소가 나타납니다.
   `https://내아이디.github.io/nurse-quiz/`
   이 주소를 휴대폰 홈 화면에 추가해 두면 앱처럼 쓸 수 있어요.

### 문제를 고치거나 추가했을 때

저장소에서 **Add file → Upload files** 로 바뀐 파일을 다시 올리고 **Commit changes** 를 누르면, 1~2분 뒤 사이트에 반영됩니다.

## 3. 문제 추가하는 법

문제는 `data` 폴더의 파일에 들어 있어요.

| 파일 | 과목 | 시험 문항 수 |
|---|---|---|
| `data/q-basic.js` | 기초간호학 개요 | 35 |
| `data/q-health.js` | 보건간호학 개요 | 15 |
| `data/q-public.js` | 공중보건학 개론 | 20 |
| `data/q-practice.js` | 실기 | 35 |

파일 맨 끝의 `);` 바로 앞에 아래 형식으로 한 문제씩 추가하면 됩니다. (앞 문제의 `}` 뒤에 쉼표 `,` 를 꼭 붙이세요)

```js
  {
    id: "basic-036",          // 겹치지 않는 고유 번호
    subject: "basic",         // basic / health / public / practice 중 하나
    topic: "성인간호",         // 세부 주제 (화면에 표시됨)
    q: "문제 내용",
    choices: ["보기1", "보기2", "보기3", "보기4", "보기5"],
    answer: 2,                // 정답 위치: 첫 번째 보기가 0, 두 번째가 1 ... 다섯 번째가 4
    exp: "해설 내용"
  }
```

- **answer는 0부터 셉니다.** 정답이 ③번이면 `answer: 2` 입니다.
- 문제가 과목별 시험 문항 수보다 많아지면, 모의고사를 볼 때마다 그중에서 무작위로 뽑아 출제돼요. 문제를 많이 넣을수록 매번 다른 시험이 됩니다.
- 새 파일(예: `data/q-basic-2.js`)을 만들었다면 `index.html` 아래쪽 `<script src="data/...">` 목록에 한 줄을 추가해 주세요.
